# Skill matrix

Оценка 0–4: 0 — подтверждённый пробел; 1 — объясняет базу; 2 — решает типовой кейс самостоятельно; 3 — диагностирует сложный отказ и защищает компромиссы; 4 — проектирует, валидирует и объясняет решения на уровне ответственности за систему/команду. «Не оценено» не равно 0. Самооценка и опыт не заменяют evidence.

| Компетенция | Контекст опыта (не оценка) | Подтверждённый балл | Цель | Доказательство |
|---|---|---|---|---|
| Linux/Bash | Эксплуатация Linux | Не оценено | 3–4 | LAB-001 + диагностика |
| Сети/DNS/TLS/HTTP | Production troubleshooting | Не оценено | 3–4 | LAB-001 + сетевой стенд |
| Docker/OCI | Контейнеризация | Не оценено | 3 | Сборка, отказ, ревью |
| Ansible | Практический опыт | Не оценено | 3–4 | Роль, идемпотентность |
| CI/CD | Jenkins/GitLab CI | Не оценено | 3–4 | Pipeline, rollback |
| Terraform | Требуется диагностика | Не оценено | 3 | Plan, state, drift |
| Kubernetes/Helm | Требуется диагностика | Не оценено | 3–4 | Локальный кластер, отказ |
| GitOps | Требуется диагностика | Не оценено | 3 | Drift/reconciliation |
| Observability/SRE | Zabbix, инциденты | Не оценено | 3–4 | SLO, алерты, RCA |
| Security | Требуется диагностика | Не оценено | 3 | Threat model, hardening |
| Platform/HA/DR | Требуется диагностика | Не оценено | 3–4 | ADR, RPO/RTO, recovery |
| Leadership | Требуется диагностика | Не оценено | 3–4 | Incident command, приоритизация |

Обновляет только Orchestrator после проверенного handoff. Фиксировать дату, ID задачи, ссылку на SHA/PR, результат экзамена, ограничения. Балл 4 требует нескольких независимых доказательств; лаборатория не доказывает коммерческий стаж. Не вычислять «процент готовности» из неизвестных баллов.
