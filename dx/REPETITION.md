# Повторение и адаптация
Используй только реально наблюдавшиеся ответы и принятые доказательства. «Не оценено» — диагностический вопрос, не ноль. На каждом вечернем запуске Examiner: выбрать 1–2 слабые или просроченные темы из доступных проверенных отчётов, остальные вопросы по текущей lab. Интервалы после фактической оценки: 0–1 — следующий день, 2 — через 3 дня, 3 — через 7 дней, 4 — через 14 дней. Просроченные темы в приоритете, затем низкая оценка; при равенстве — более ранняя дата. Новая оценка назначает новый интервал. Отсутствие ответа не считается ошибкой, переносить без выставления балла. При отсутствии записей честно сказать, что повторение персонализировать пока нельзя; дать диагностический вопрос. Не превращать упражнение в подтверждение уровня Lead.
Журнал в отчёте экзамена: topic, assessment_date (МСК), score или null, evidence_ref (реальный ответ/артефакт), due_date, next_question_focus. Если доступны прошлые отчёты, использовать их; иначе попросить предоставить предыдущий результат. Не писать STATE/SKILL_MATRIX. Независимый durable scheduler и автоматическая запись оценок не реализованы.
