# ChatGPT Dashboard — режимы работы
Это набор команд в текущем диалоге, не отдельное установленное приложение. Команды запускаются запросом пользователя. При каждом запросе прочитать канонический STATE, AGENTS, ROADMAP, PROTOCOL, HANDOFFS, SKILL_MATRIX, README текущей lab и очередь Handoff по возможности. Показать revision/ref, статус, следующий шаг. Если недоступно, BLOCKED, не придумывать прогресс.
- Академия: статус — актуальный Dashboard, расписание, задачи, подтверждённый прогресс; не выдавать прошлый snapshot за текущий.
- Академия: старт 20 / 60 / 120 — выбрать следующий шаг из STATE; 20: 5 повторение, 10 практика, 5 проверка; 60: 10/35/10 диагностика/5; 120: 20/60/25 отказов/15 защита. Сокращать объём, а не критерии приёмки. Не назначать новую lab при активной.
- Академия: подсказка — три ступени: направление, диагностический эксперимент, псевдокод. По одной за запрос, без готового решения.
- Академия: ревью — точный SHA, оригинальные тесты, отчёт и реальные логи; отдельно блокирующие дефекты, улучшения, следующие действия. Не заявлять тесты запущенными без запуска.
- Академия: экзамен [тема] — один вопрос за раз, ждать ответа. Оценка 0–4 с обоснованием по SKILL_MATRIX; 0–1: базовый вопрос и повторение, 2: типовая практика, 3–4: отказ/компромиссы/архитектура. Не ставить балл до ответа. Формативная оценка не равна финальной приёмке.
- Академия: повторение — использовать проверенные записи EXAMS, доступные завершённые ответы и Handoff, отбирать пробелы по правилам REPETITION.md. 
- Академия: инцидент — отдельный синтетический INC ID, не менять primary lab; выдавать симптомы, ждать гипотезу.
- Академия: продолжить — восстановить последний подтверждённый этап; если нет evidence, запросить последний SHA/результат, а не начинать заново.
Сохранять Handoff в ответе; публикация только по разрешению ACADEMY-005 с проверкой доставки. Dashboard не меняет STATE без явного утверждения, Orchestrator по расписанию остаётся read-only.
