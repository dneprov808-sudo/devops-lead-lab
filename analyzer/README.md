# Analyzer bridge v1
The local Ollama analyzer produces output/interview/analysis.json (or output/web). Its exact raw schema was not available at implementation. This bridge deliberately does NOT guess the schema or silently convert raw scores. Map relevant findings to analyzer/example.json using actual stored attempt UUID and question ID; choose a 0–4 rubric score only with a human check, retain evidence excerpt. Keep raw audio/transcripts private. Preview: python3 analyzer_bridge.py mapped.json. Import explicitly: python3 analyzer_bridge.py mapped.json --apply. The local database requires a matching attempt and stores review_proposal only. Re-import same IDs is idempotent; different payload collision rejected. No LLM call, no GitHub upload, no canonical grade. Native analysis.json adapter requires actual schema/sample and tests.
