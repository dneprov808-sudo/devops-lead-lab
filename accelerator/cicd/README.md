# CI-ACC-01 — неизменяемый артефакт
Дополнительная практика ACADEMY-017. Реализуй release.py: CLI `build SOURCE ARTIFACT`, `verify ARTIFACT DIGEST`. Build копирует байты SOURCE в новый ARTIFACT (не перезаписывает существующий), печатает SHA256 в stdout. Verify возвращает 0 только при совпадении SHA256, иначе ненулевой код. Ошибки не должны менять артефакт. Запусти `python3 -m unittest discover -s accelerator/cicd -v` из корня. Затем самостоятельно составь Jenkinsfile и GitLab CI с build/test/promote одного артефакта, без повторной сборки, с ручным production approval. Не подключай реальные окружения. Ревью pipeline отдельно от CLI тестов. Документация: https://docs.gitlab.com/ci/jobs/job_artifacts/ и https://www.jenkins.io/doc/book/pipeline/jenkinsfile/ .
