# K8S-ACC-01 — Service и readiness
Дополнительная практика ACADEMY-017, не заменяет LAB-001. На WSL с Docker, kind и kubectl создайте отдельный кластер: `kind create cluster --name academy-v9 --kubeconfig ./academy-v9.kubeconfig --wait 120s`. Не используйте рабочий kubeconfig. Примените starter.yaml только через `kubectl --kubeconfig ./academy-v9.kubeconfig --context kind-academy-v9 apply -f starter.yaml`. Найдите причину отсутствия готовых endpoints, исправьте конфигурацию самостоятельно. Запустите `python3 verify.py`. Объясните различие readiness и liveness, приложите SHA и вывод. Удаление только учебного кластера: `kind delete cluster --name academy-v9 --kubeconfig ./academy-v9.kubeconfig`. Документация: https://kind.sigs.k8s.io/docs/user/quick-start/ и https://kubernetes.io/docs/concepts/services-networking/service/ . Runtime пока не проверен.
