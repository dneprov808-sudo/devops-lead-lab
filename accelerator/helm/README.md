# HELM-ACC-01 — параметризация chart
Дополнительная практика ACADEMY-017. Исправь chart так, чтобы replicas из values управляло Deployment, добавь readiness probe и Service с согласованным selector. Не используй production. Из корня репозитория: `helm lint accelerator/helm`, `python3 accelerator/helm/verify.py`. Проверка рендеринга не доказывает работоспособность кластера. Для GitOps самостоятельно опиши Application с source.path accelerator/helm, точным targetRevision учебного коммита и выделенным namespace academy-v9; сначала ручная синхронизация, затем эксперимент с drift в отдельном Kind. Не включай автоматический prune до проверки diff. Источники: https://helm.sh/docs/chart_template_guide/values_files/ и https://argo-cd.readthedocs.io/en/stable/user-guide/auto_sync/ . Argo CD runtime не проверен.
