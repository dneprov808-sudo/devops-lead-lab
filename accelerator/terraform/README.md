# TF-ACC-01 — стабильные адреса ресурсов
Создай по одному terraform_data на каждый ключ services с помощью for_each. Выведи map версий из атрибутов input созданных ресурсов. Встроенный provider, без облака. `terraform init -backend=false`, `terraform validate`, `terraform test`. Начальный тест должен падать. Дополнительно покажи plan после добавления ключа и объясни почему соседние экземпляры не пересоздаются. Не коммить state или .terraform. Источник: https://developer.hashicorp.com/terraform/language/resources/terraform-data и https://developer.hashicorp.com/terraform/language/tests . Тест проверяет output, адреса и связь с ресурсами проверяются ревью. Runtime не проверен.
