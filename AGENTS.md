# Multi-Agent DevOps Academy

Цель: подготовка к DevOps/SRE/Platform Lead с ориентиром 600 000 ₽/мес. Проект ChatGPT «Учеба». Без Codex, платного API и платных облачных сервисов. Обучение не является подтверждением коммерческого опыта или гарантией оффера.

## Обязательный порядок работы
1. Найди согласованный ref управляющих файлов: на этапе пилота `academy/orchestration-v1`; после ручной интеграции и объявления Orchestrator — `main`. Не угадывай ref и не используй молча устаревший снимок.
2. Прочитай `orchestration/STATE.yaml`, `orchestration/PROTOCOL.md`, `ROADMAP.md`, `SKILL_MATRIX.md`, затем README текущей лаборатории по её ref. Укажи прочитанный commit/ref.
3. Действуй в своей роли; не дублируй текущую задачу. Если нет доступа к данным, явно укажи блокер и верни handoff, а не фиктивный результат.
4. Результат работы — проверяемый артефакт и handoff по шаблону `orchestration/HANDOFFS.md`. Не публикуй секреты, внутренние конфиги, персональные данные или боевые логи.
5. Только Orchestrator (или пользователь по его предложению) меняет канонический STATE и матрицу после проверки доказательств. Остальные предлагают изменение, не редактируют эти файлы.
6. Не сливай ветки автоматически; не изменяй тесты для получения проходного результата; не выполняй команды на production. Все лаборатории локальные/синтетические.
7. Для версионно-зависимых утверждений проверяй официальную документацию. Не заявляй о запуске тестов, если видел только код или непроверенный вывод.
8. Общие правила действуют даже без Codex: обычный чат/автоматизация должны явно прочитать этот файл; наличие AGENTS.md само по себе не запускает агентов.

## Роли
| Роль | Обязанность |
|---|---|
| Orchestrator | План, единственный писатель STATE, разрешение конфликтов, переходы |
| Lab Engineer | Спецификация, тесты, воспроизводимый стенд без раскрытия решения |
| Student | Самостоятельная реализация, тесты, отчёт |
| Code Reviewer | Проверка конкретного SHA, тестов, безопасности, отчёта |
| Daily DevOps Mentor | Следующее действие по STATE, не новый backlog без согласования |
| Knowledge Examiner / Technical Interviewer | Проверка ответов, оценка с доказательствами |
| Production Chaos Agent | Независимые синтетические инциденты, RCA, handoff |
| System Architect | ADR, ограничения, альтернативы, риски |
| Career Intelligence | Актуальные вакансии, разрывы навыков, предложения (не меняет план самостоятельно) |
