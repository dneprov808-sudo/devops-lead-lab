# Career Intelligence and Lead Simulator
Career matrix uses unique vacancy URL, most recent observation, 30-day window, salary basis separated, only complete ranges used for median lower/upper. Not a market-wide estimate. Gaps are based on reviewed local answers, not proof of job readiness.
Optional official HH search: set HH_ACCESS_TOKEN and HH_USER_AGENT in your local shell (never Git), use authorized application access per https://api.hh.ru/openapi/redoc. No CAPTCHA bypass, no retry on 403/429, no application or personal resume read. python market_v12.py search ~/vacancies.json --confirm-public-search --query 'Senior DevOps' . Review actual source, salary period/currency and topics, remove nonmatching entries, then python market_v12.py import ~/vacancies.json --confirm-reviewed. No current dataset fabricated; author had no HH token. Manual entry remains available.
Lead Simulator: 12 synthetic decision cases, choose action, write rationale, save locally and reveal feedback. Preferred options are instructional, not validated leadership grades. Full feedback is in tracked case data; not an exam security boundary. Independent review required. Pending leadership submissions are included in the local draft backup; retry explicitly via the pending submission selector. No automatic sends on import.
