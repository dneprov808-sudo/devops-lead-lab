# Academy Learning Hub v4 — ACADEMY-011

## Обновление установленного портала (WSL)
Остановить старый процесс python3 portal.py через Ctrl+C в его терминале.
В имеющейся рабочей копии:
    cd ~/infra/devops-lead-lab
    git status --short
    git fetch origin
    git switch --track origin/academy/learning-hub-v4
    python3 portal.py

Если локальная ветка v4 уже существует: git switch academy/learning-hub-v4 && git pull --ff-only. Если есть незакоммиченные изменения, не сбрасывать и не перетирать их; использовать отдельный checkout или worktree после проверки. Если пользователь находится в student/lab-001, не заменять решение.

Открыть http://127.0.0.1:8080/ и обновить страницу Ctrl+F5. В шапке должно быть HUB V4. Проверка текущего запущенного сервера:
    curl -fsS http://127.0.0.1:8080/api/version
Ожидается JSON release Learning Hub v4, branch academy/learning-hub-v4. Это идентификатор версии кода, не фактическая текущая ветка рабочего дерева. Если 404 или старый интерфейс, проверить, что старый процесс остановлен и новый запущен из нужной копии. Не завершать произвольные процессы.

## Единое место доступа
Главная страница «Все технологии» содержит 20 карточек; Kafka, PostgreSQL, Patroni, Redis и RabbitMQ расположены первыми. Поиск учитывает название, термины, справочник, задания, названия/симптомы инцидентов, вопросы и архитектуру. Фильтр по направлениям. Карта learning/hub.json связывает существующие источники по устойчивым ID и профилям; не дублирует контент. На карточке показываются реальные количества материалов. Раскрытие темы даёт все пять разделов: теория и команды, задания и критерии, вопросы и самопроверка, синтетические инциденты, System Design. Действие «Выполнить и сохранить результат» открывает существующую форму конкретной лаборатории, с прежним явным commit+push в student/practice-results. Тренажёр и Incident Lab доступны непосредственно по выбранной теме. Вопросы по Prometheus/SRE и некоторые архитектурные упражнения используются в нескольких технологиях, общий счётчик уникальных материалов не удваивает их.

На главной также доступны обзор агентов, Roadmap, LAB-001, Skill Matrix, интервальное повторение, результаты GitHub, инженерные калькуляторы и Handoff. Старые функциональные вкладки сохранены. Каталог загружается локально и не требует успешного чтения GitHub STATE. Ошибки отдельных API отображаются как частичная загрузка; кнопка обновляет материалы. Сами ответы, введённые в быстрых карточках, не сохраняются; для интервального повторения открыть полноценный тренажёр. Для технологий без отдельного Docker-стенда указано ограничение, нет фиктивных лабораторий.
