# Academy v12 — рабочая область

## Быстрый запуск в Ubuntu WSL

Портал — отдельный checkout, не ветка решения LAB-001. Останови старый портал
через Ctrl+C. Если копия уже есть, не клонируй поверх неё и не удаляй .academy-data.
Для сохранения браузерных черновиков используй тот же адрес (localhost и
127.0.0.1 имеют разные localStorage). Перед изменением версии сохрани резервную
копию по [инструкции восстановления](release/V12_RECOVERY.md).

```bash
cd ~
git clone -b academy/stable git@github.com:dneprov808-sudo/devops-lead-lab.git academy-portal
cd academy-portal
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-v11-dev.txt
python portal.py
```

Открой http://127.0.0.1:8080/ в Windows. Docker для портала не нужен.
Установи Python 3.12–3.14, python3-venv и Git, если их ещё нет. Node 22
нужен для регрессионных тестов, не для отображения портала.
Для существующей чистой копии stable: `git pull --ff-only origin academy/stable`,
активировать прежнее venv и обновить зависимости; не переключать ветку с
незакоммиченными работами.

## Workbench: пять рабочих областей

| Область | Действия |
| --- | --- |
| Сегодня | Текущая каноническая задача, этапы проверки, локальная статистика |
| Учебные материалы | Каталог технологий, справочник, повторение |
| Практика и стенды | Развёртывание одного стенда, LAB-001, практикум, инциденты, архитектура, модели |
| Собеседования | Банк вопросов с панелью фильтров, mock, Lead-тренажёр |
| Результаты | Личный прогресс, независимая оценка, GitHub, карьера, агенты |

Главная не показывает выдуманный процент освоения: текущая задача приходит из
STATE, статистика попыток — из локального SQLite. При недоступности источника
показывается «—» или ошибка, не ноль. Самооценка не равна квалификации.

В каталоге технологий открывается отдельный экран с пятью вкладками. При
смене вкладки уже созданные поля не пересоздаются. В практикуме каталог
отделён от рабочего экрана задания: команды и требования слева, критерии
и сохранение доказательств справа. Сохранение по-прежнему явно инициирует
пользователь, правила черновиков и API не изменены.

**Развёртывание:** выбери один из девяти runbook в левом списке.
Справа только выбранный стенд; команды можно копировать, но портал их
не исполняет. Например, адрес http://127.0.0.1:8080/#deploy-ha открывает HA,
а #hub — каталог. Ссылки на экраны и runbook работают после перезагрузки;
кнопка браузера «Назад» возвращает предыдущий экран. На мобильном экране
навигация сворачивается. Светлая и тёмная темы сохранены.

## Learning Cockpit

- «Мой день»: текущая задача из STATE, локальные результаты, путь к практике и продолжение последней выбранной главы.
- Ctrl+K / Cmd+K: быстрый переход по разделам, runbook и загруженным технологиям. Enter открывает первое совпадение, Escape закрывает диалог.
- Reader: выбери главу в содержании, читай одну главу за раз; на широком экране есть дополнительное оглавление разделов. Позиция хранится в отдельном локальном ключе academy-ui-reading-v12, не является прогрессом или подтверждением компетенции.
- Среды → Развёртывание: выбирай стенд и этап, копируй команды вручную. Режим «Все команды» показывает исходный runbook целиком. Критерий результата остаётся видимым; интерфейс не проверяет состояние Docker/kind и не запускает команды.
- Теория → связанная практика или инструкция подходящей локальной среды. Не поднимай все стенды сразу.
- Быстрый переход не меняет учебные данные. Тема и прежние черновики сохраняются независимо.

Дизайн опирается на навигационные паттерны [Grafana Saga](https://grafana.com/developers/saga/patterns/navigation/),
[Primer](https://primer.style/) и семантические рекомендации [W3C WAI](https://www.w3.org/WAI/tutorials/page-structure/).
Это собственная реализация без новых зависимостей.

## Расширенная теория

20 направлений включают 96 учебных глав: 60 обзорных и 36 углублённых.
Linux, Docker, Kubernetes, Ansible, Terraform и CI/CD содержат по девять глав,
остальные направления — по три. В новых главах есть 36 аннотированных примеров
конфигураций и кода (Bash, systemd, Dockerfile, YAML, HCL, Groovy). Это фрагменты
для изучения, не готовые production-конфигурации; зависимости и версии описаны в тексте.
Открой «Учебные материалы → Каталог технологий → технология → Теория и команды»
или «Справочник». В обоих местах используется один набор данных learning/knowledge.json.
В каждой главе: механизм работы, production-нюансы, пример, диагностические команды,
вопрос для самостоятельной защиты и ссылка на документацию. Старые памятки сохранены.
Команды являются контекстными примерами, а не универсальными сценариями запуска:
используй только соответствующую изолированную лабораторию, подставляй её имена и адреса,
SQL выполняй в psql, PromQL — в Prometheus, перед Terraform plan проверь backend/provider.
Ссылки и параметры сверяй с версиями своего стенда. Изучение главы не подтверждает компетенцию.

## Карта окружений

| Что | Где | Порт / изоляция |
| --- | --- | --- |
| Портал | WSL Python, checkout stable | 8080 loopback |
| LAB-001 | Отдельный student checkout | 18080 optional local fixture |
| Production Light | Docker Compose, production_v11/compose.yaml | 18111, Prometheus 19111 |
| Production HA | Docker Compose, три overlay файла | 18112 LB, 18111 API, 19111 Prometheus |
| Kubernetes | kind academy-v11, отдельный kubeconfig | Только dedicated cluster |
| Linux | disposable WSL/VM, user namespace | Не изменять host firewall/routes |
| IaC | disposable VM/каталог, local provider | Без облака |
| CI/CD | локальный pipeline, отдельный checkout | Без production runner |
| Legacy Production v8 | отдельный старый стенд | 18088 |

Light и HA не запускать одновременно (пересекаются порты). В UI есть
команды запуска каждого сценария, но портал их не исполняет. Перед
повторным запуском проверить существующие контейнеры/кластеры. Все данные
синтетические. Не удалять volumes, kubeconfig или учебные результаты
без отдельного решения. Старый /api/production/status относится к v8.

Подробности: [HA acceptance](release/V12_INFRA_ACCEPTANCE.md),
[K8s labs](v12-labs/k8s/README.md), [Linux](v12-labs/linux/README.md),
[IaC](v12-labs/iac/README.md), [CI/CD](v12-labs/cicd/README.md).
Не считать наличие runbook доказательством успешного runtime.

## Приёмка

В чистом checkout, без запущенного портала:
```bash
source .venv/bin/activate
python -m unittest -v test_workspace_ui
node test_frontend.mjs
node test_ui_preferences.mjs
node test_workbench.mjs
node test_theory_curriculum.mjs
node test_learning_cockpit.mjs
python -m playwright install --with-deps chromium
python release/browser_e2e.py
python release/gate.py --full
```
Затем открыть портал и проверить desktop/mobile, навигацию, копирование
команд, фильтры каталога, сохранение локальной попытки и восстановление
черновика. Не использовать реальные ответы при тестировании.
