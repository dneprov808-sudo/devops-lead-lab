# IaC Pro supplementary labs
These do not alter accelerator/terraform or existing Ansible exercises.
Ansible: dedicated disposable VM, Python/ansible-core installed. Start from playbook and role under ansible/. Goal: service.conf content exactly mode=production-like newline, 0640 mode, second run changed=0. Role may write only academy_work in temp dir. Run python v12-labs/iac/ansible/verify.py. Review diff before applying. Optional ansible-lint installed locally; check mode does not prove actual application.
Terraform: copy terraform/ into an isolated new work directory. Terraform 1.9.x with local provider 2.5.3; terraform init downloads provider (free) and generates lock, keep lock. terraform test; plan/apply initial v1 after checking no external resources; manually edit generated service.conf in .lab-data to introduce drift; run terraform plan -detailed-exitcode -var=version=v2 -out=review.tfplan; exit 2 means diff. terraform show -json review.tfplan > plan.json; python verify_plan.py plan.json. Review and apply saved plan locally, verify file and idempotence. To roll back desired version, create a new reviewed v1 plan; never overwrite state to simulate rollback. Preserve state backup and test evidence locally, no real secrets. All commands limited to synthetic files and local provider; do not run in production directories.
Ansible/Terraform runtime and provider downloads not executed by author.
